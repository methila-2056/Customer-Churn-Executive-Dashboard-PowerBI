# Contributing to Customer Churn Executive Dashboard

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion for improvement:

1. Check existing [issues](https://github.com/methila-2056/Customer-Churn-Executive-Dashboard-PowerBI/issues) to avoid duplicates
2. Open a new issue with a clear title and description
3. Include steps to reproduce if reporting a bug

### Suggesting Enhancements

1. Open an issue describing the enhancement
2. Explain the use case and expected benefit
3. Include mockups or examples if applicable

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature-name`)
3. Make your changes
4. Test your changes in Power BI Desktop
5. Commit with a clear message (`git commit -m "Add: description of change"`)
6. Push to your branch (`git push origin feature/your-feature-name`)
7. Open a Pull Request with a detailed description

## Guidelines

- Follow existing dashboard design patterns
- Ensure all visuals are properly labeled and accessible
- Test interactions and filters before submitting
- Update documentation if adding new features

## Questions?

Feel free to open an issue for any questions about contributing.
