## FAQ

**Q: The dashboard shows an error when opening.**
A: Ensure you have Power BI Desktop installed. Download it from [powerbi.microsoft.com](https://powerbi.microsoft.com/downloads/).

**Q: Data is not refreshing.**
A: Check that `churn-bigml-80.csv` is in the same directory as the `.pbix` file.

**Q: How do I customize the dashboard?**
A: Open the `.pbix` file in Power BI Desktop and modify visuals as needed. Refer to the [DAX documentation](https://docs.microsoft.com/en-us/dax/) for measure modifications.
